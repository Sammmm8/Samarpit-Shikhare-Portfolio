# CREWMATE / DEV — Among Us Inspired Portfolio

A responsive personal portfolio website with a space/Among Us-inspired theme.

## Sections included
- Home with animated CSS crewmate
- About and Education
- Skills (Python, Excel, UI/UX, programming and tools)
- Projects with category filters
- Achievements and certifications
- Learning Journey timeline
- Contact with GitHub, LinkedIn and email links

## Folder structure
```text
amongus_portfolio/
├── index.html
├── README.md
└── assets/
    ├── css/style.css
    ├── js/script.js
    └── images/
```

## Run in VS Code
1. Extract the ZIP file.
2. Open VS Code and choose **File → Open Folder**.
3. Select the `amongus_portfolio` folder.
4. Install the **Live Server** extension if you do not have it.
5. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser.

## Personalise before publishing
Search in `index.html` and replace:
- `YOUR NAME` with your name.
- `YOUR CITY, INDIA` with your location (or remove it).
- `Degree / Course Name`, `College / University Name`, school and year with your real education details.
- Sample achievement and certificate names with your real milestones.
- `https://github.com/YOUR-USERNAME` with your GitHub profile URL.
- `https://www.linkedin.com/in/YOUR-USERNAME/` with your LinkedIn profile URL.
- `your.email@example.com` with your email address.
- Sample project names and descriptions with your own work.

The crewmate illustration is made with CSS, so no image assets are required.
